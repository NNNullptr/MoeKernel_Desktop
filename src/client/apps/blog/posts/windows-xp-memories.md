# Windows XP 的回忆

*写于一个怀旧的午后*

---

## 那个年代

Windows XP 于 2001 年 10 月 25 日正式发布。它有着标志性的**蓝天白云**壁纸（Bliss），那张照片拍摄于美国华盛顿州的纳帕山谷。

那片绿色的山丘，那片湛蓝的天空，成为了无数人开机时的第一眼记忆。

## Frutiger Aero 美学

与 XP 同时代的还有 **Frutiger Aero** 设计风格——一种融合了：

- 半透明玻璃质感
- 自然元素（水、天空、植物）
- 高光与反射效果
- 清澈的蓝色调

这种风格在 2004-2013 年间风靡全球，从手机壁纸到广告设计无处不在。

## 经典的声音

还记得那些声音吗？

| 场景 | 音效 |
|------|------|
| 开机 | 那段悠扬的启动音乐 |
| 登录 | 欢快的叮声 |
| 错误 | 低沉的提示音 |
| 关机 | 渐弱的旋律 |

这些声音由 Brian Eno 等音乐人设计，每一个都精心打磨，只有短短几秒，却留在了记忆深处。

## 为什么怀念它？

XP 时代的互联网是**慢而有温度**的。网页是手写的 HTML，论坛是真实的社区，每个人的主页都有自己独特的 GIF 动图和背景音乐。

那时候的数字世界，还带着人类的体温。
